How the value is worked out

implied = TVL × peer multiple × growth × maturity × breadth

  • Peer multiple — the median market-cap / TVL of the tokenised protocols in the same category (at least 3 peers, else the global median). Market cap here is circulating, not fully diluted, so the multiple is a floor, never a forecast.
  • Growth — the protocol's 7-day TVL change, clamped to −50…+150%, at 0.6% of value per point.
  • Maturity — saturating with age: 0.70 + 0.30 × age / (age + 365). A year running with no token gets most of the way there.
  • Breadth — +2% per extra chain, up to 8 extra chains.

No protocol name is ever special-cased. The watchlist is the floor, never the ceiling: every rankable pre-token protocol in the snapshot is ranked, watchlist or not.
